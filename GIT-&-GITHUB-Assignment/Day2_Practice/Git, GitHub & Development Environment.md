# Day 2 - Git, GitHub & Development Environment

## Assignment 1 - Git vs GitHub

### 1. What is Git?

Git is a version control system which is used to track the changes made in a project. It helps us to save different versions of our code and go back to an older version if needed.

### 2. What is GitHub?

GitHub is an online platform where we can store Git repositories. It helps us to share our code, work with other people and manage our projects online.

### 3. Difference between Git and GitHub

| Git                                 | GitHub                                 |
| ----------------------------------- | -------------------------------------- |
| Git is a version control system.    | GitHub is an online platform.          |
| It is installed on our computer.    | It works mainly through the internet.  |
| It manages the history of our code. | It stores and shares Git repositories. |
| We can use Git without GitHub.      | GitHub is mainly used with Git.        |

### 4. Explain Git and GitHub using the Taxi and Uber/Ola example.

Git is like a **taxi** because it is the actual system used to manage the journey. GitHub is like **Uber/Ola** because it provides an online platform to access, share and manage the service. In the same way, Git manages our code and GitHub provides an online place to store and collaborate on it.

## Assignment 2 - Development Environment & IDE

### 1. What is a Development Environment?

A Development Environment is a collection of tools that we need to write, test and manage our programs.

For example, while writing something on paper we need a pen and paper. Similarly, while developing software we need a code editor, terminal, Git, browser and other tools. All these tools together make our Development Environment.

### 2. What does IDE stand for?

IDE stands for **Integrated Development Environment**. It provides different development tools in one application, such as a code editor, debugger, terminal and other features.

### 3. Advantages and disadvantages of using an IDE

**Advantages:**

1. It makes coding easier and faster.
2. It provides code suggestions and auto-completion.
3. Debugging becomes easier.
4. Many tools are available in one place.

**Disadvantages:**

1. Some IDEs use a lot of RAM.
2. Beginners may find some IDEs difficult to understand.
3. Some IDEs may have paid features.

### 4. Give 5 examples of IDEs or Code Editors.

1. Visual Studio Code
2. IntelliJ IDEA

### 5. Why is VS Code popular among beginners?

VS Code is popular because it is free, lightweight and easy to use. It supports many programming languages and provides useful extensions. It also has a built-in terminal and Git support.

A repository is a storage place for a project. It contains the project files as well as the history of changes made to those files.

### 2. Answer the following questions

#### Can we use Git without GitHub? Explain.

Yes, we can use Git without GitHub. Git works on our local computer and can track all the changes made to our project. We can create commits and maintain the project history without using GitHub. GitHub is mainly useful for storing and sharing the repository online.

#### Can we use GitHub without Git? Explain.

GitHub is mainly made for hosting Git repositories. We can use some GitHub features directly from the website, but Git is needed for normal version control operations like commits, branches and merging. Therefore, Git and GitHub are commonly used together.

#### Why do we need a proper Development Environment?

A proper Development Environment gives us all the tools required for software development in one setup. It helps us write, test, debug and manage our code easily. It also saves time because we do not need to use different tools for every task.

### 3. Four key takeaways from Day 2

1. Git helps us track and manage changes in our projects.
2. GitHub helps us store and share Git repositories online.
3. A Development Environment contains the tools needed for software development.
4. VS Code is a useful code editor with features like extensions, terminal and Git support.
